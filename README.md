# AI Caption Generator

An AI-powered MERN stack web application that generates social media captions using OpenRouter API.

## Features
- Generate AI captions
- Modern responsive UI
- React frontend
- Express backend
- OpenRouter AI integration

## Tech Stack
- React.js
- Node.js
- Express.js
- CSS
- OpenRouter API

## Installation

### Backend

```bash
cd server
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm start
```
